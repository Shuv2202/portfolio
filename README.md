# Shubham Kumar — Creative Portfolio

An interactive personal portfolio inspired by a physical creative desk. Built with Next.js, React, TypeScript, and responsive CSS.

## Highlights

- Layered animated workspace hero
- Responsive mobile navigation and stacked desk layout
- Project explorer with category filters and case-study dialogs
- Interactive terminal commands
- Scroll reveals, progress indicator, focus-mode vinyl interaction
- Accessible keyboard focus, escape-to-close, and reduced-motion support
- SEO and social metadata

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in your terminal.

## Build

```bash
npm run build
```
